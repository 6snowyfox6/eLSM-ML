# Schaefer & Wagner, PRD 79, 014018 (2009), arXiv:0808.1491 — результат

**Класс A, p1, группа SW-PQM.** Ссылка [59] опорной статьи.

## Что прогнано
14 наборов из таблицы II (m_σ = 400…1000 МэВ, c = 0 и c = 4807.84 МэВ), сравнение с вакуумными массами из таблицы I.
Модель — U(3)×U(3) LSM без векторов (Z_i = 1), σx = f_π = 92.4, σy = (2f_K − f_π)/√2 = 94.47 МэВ (в статье 94.5).
Инструмент: `tools/vacuum_check.py`, данные: `params.yaml`, полный вывод: `vacuum_check.md`.

## Результат: совпадение
- Все 8 каналов (π, K, η, η′, σ, f0, a0, κ) во всех 14 наборах: max |отн. откл.| ≤ 2.5·10⁻³.
- Наибольшее отклонение у пиона (до −0.35 МэВ) и в h_x (до 0.5%): это округление напечатанных λ1 (2 знака) и m²
  при почти полном сокращении в m_π² = h_x/σx. Остальные каналы — ≤ 5·10⁻⁴.
- h_y из стационарности — совпадение ≤ 3·10⁻⁴.

## Сверка формул
Формулы приложения B (B2)–(B10) совпадают с исправленной таблицей A1 решателя:
аномальный член a0 = +√2c/2·σy, κ (K0*) = **+c/2·σx** — независимое подтверждение исправления K0* (CHANGELOG_FIX.md).

## Что не прогнано (фичи, только запись)
- Конечная T: модель QM **без петли Полякова** — в решателе нет такого режима.
- Таблица III: вторые производные m_q² по мезонным полям (σ0, σ8, σ1, σ4, π0, π8, π1, π4) — входные данные для открытой
  задачи №2 (термальные массы по каналам). Записано, не использовано.
- Массы и углы смешивания от T (рис.) — нужна задача №2.
