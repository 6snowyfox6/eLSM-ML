# Zacchi & Schaffner-Bielich, arXiv:1909.12071 (2019) — результат

**Класс A, p2, SW-QM-params.** Прогнаны 6 наборов MFA (таблица I, верх; m_σ = 400…900), Z=1, σx=92.4, σy=94.47.
Строки eMFA (с вакуумным членом фермионов, Λ=200 МэВ) — фича.

## Результат
- Наборы MFA — это наборы SW 2009 (c≠0), пересчитанные с бóльшим числом знаков. Решатель даёт m_π = 138.0, m_η = 539.0,
  m_η′ = 963.0, m_K = 495.9, m_σ = m_σ^vac (≤ 3·10⁻⁴) для m_σ = 500…900 — **совпадение с SW**.
- **Расхождение с текстом статьи:** в тексте указаны входы m_π = 136, m_η = 548, m_η′ = 958, но напечатанные h_n = (120.73)³
  и остальные параметры дают m_π = 138.0 (как у SW). η/η′ по отдельности не воспроизводятся, потому что фит (как у SW) фиксирует
  только сумму m_η² + m_η′²: 539² + 963² = 1 217 890 ≈ 548² + 958² = 1 218 068 (0.01%) — это согласуется.
- **Опечатка в строке m_σ = 400:** m² = (494.272)² несовместимо с h_n (h_x из стационарности −2.4%). Согласованное значение
  m = 494.73 МэВ (у SW — 494.75) → вероятно, перестановка цифр «494.272» вместо «494.72».

## Не прогнано
eMFA (вакуумный член), нейтронные звёзды (T=0, μ>0, векторное отталкивание g_ω, мешок B) — вне решателя.
