## Вакуум (найдена опечатка)
- m_σ=400, 500: m_π, m_K, m_σ воспроизводятся (≤ 0.3%; h_x ≤ 0.7% — округление).
- **m_σ=600: напечатанное λ1 = 1.141 несовместимо с остальными параметрами** — с ним h_x из стационарности на 24% ниже
  напечатанного, m_π = 120 вместо 138. Согласованное значение λ1 = 1.405 (≈ 1.40 у SW 2009) → в таблице, вероятно,
  «1.141» вместо «1.41». T-скан с λ1=1.141 всё равно даёт 172.5 (vs 171.9) — T_χ слабо чувствителен.
