# Metzger, Meyer-Ortmanns, Pirner hep-ph/9312252 (1993) и hep-ph/9410264 (1994) — результат

**Класс A?, LSM-vacuum.** Древесная U(3)×U(3) LSM в конвенции Φ = λ_a φ_a/√2. Перевод в конвенцию решателя:
m² = −μ0², λ1 = 4f1, λ2 = 4f2, c = 2√2|g|, h0 = ε0, h8 = ε8 (нормировка полей совпадает). Вакуум найден минимизацией
`mesonic_potential` решателя при напечатанных ε (f_K не нужен), затем массы по таблице A1 (Z=1).
Скрипт: `runs/lsm_vacuum_minimize.py`, вывод: `vacuum_minimize.md`. Перебор знака c и прочтений OCR (f1↔f2): `vacuum_check.md`.

## Metzger 1993 — совпадение
f_π 92.97 (93), f_K 128.78 (128.81), π 138.11 (138.04), K 495.70, η 547.49, η′ 957.77, σ(f0′) 764.57 (764.71),
f0 1586.65 (1590), a0 914.04 (914.05), K0* 913.29 (913.35) — всё ≤ 0.2% при μ0² с тремя значащими цифрами.
Третья независимая конвенция (после Lenaghan/Röder и SW), подтверждающая формулы таблицы A1, в т.ч. аномальный член K0*.

## Pirner 1994 — не проверяется из-за точности печати
Параметры с 2–3 значащими цифрами (μ0²=0.059, g=−1.8, ε0=0.026, ε8=−0.035); h_x = (√2ε0+ε8)/√3 — разность почти равных
чисел (±0.0005 в ε0 → ±40% в h_x). Результат: f_π 101 (94), π 100 (130) — неинформативно; тяжёлые каналы K, η, η′, f0, a0, K0*
согласуются в пределах ≤ 2.3%. Ошибкой ни решателя, ни статьи не считается.

Конечная T в обеих статьях — свои резуммированные схемы (Hartree-подобная/все мацубаровские частоты) — фича.
