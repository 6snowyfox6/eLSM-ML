# Törnqvist, Eur. Phys. J. C 11, 359 (1999), hep-ph/9905282 — результат

**Класс A?, LSM-vacuum.** Древесная U(3)×U(3) LSM в базисе (u, d, s). Перевод из формул масс статьи (Eqs. 3–10):
σx = √2u = f_π, σy = s; λ2 = 4λ, λ1 = 4λ′, c = −2√2β, m² = μ̄² − λ1(σx²+σy²). Параметры Eq. (16): λ=11.57,
μ̄²=0.1424 ГэВ², β=−1701 МэВ, u=65.35, s=94.45 МэВ (σy = (2f_K−f_π)/√2 = 94.455 — совпадает).

## Результат
- **λ′ = 1: совпадение всех 8 каналов** (π, K, η, η′, σ, f0, a0, κ) с точностью ≤ 1.5·10⁻³.
- Отображение подтверждено независимо: при λ′ = 4.5 решатель даёт m²_σNS = −1·10⁻⁴ ≈ 0 — ровно «точная компенсация OZI при
  λ′ = −β/(4s) = 4.5», о которой пишет статья.
- **λ′ = 3.75: столбец таблицы I не согласуется с формулами самой статьи.** Решатель: σ = 817, f0 = 1285 (статья 619, 1188).
  m_σ монотонно растёт с λ′ (459/566/651/721/817/849 при λ′ = −1/0/1/2/3.75/4.5), f0 тоже растёт; значения статьи (σ↓, f0↓
  при λ′↑) не достигаются ни при каком λ′ ≥ −1 одновременно. Вероятно, этот столбец посчитан с иными μ̄²/λ или опечатка.
  Не подгонялось, задокументировано. Псевдоскаляры, a0, κ от λ′ не зависят — совпадают в обоих столбцах.
