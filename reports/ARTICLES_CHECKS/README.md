# Проверка решателя по статьям архива eLSM (только SU(3))

Решатель (`src/elsm`) при проверках **не изменялся**: все прогоны собраны из его публичных функций.
Тексты статей сюда не входят.

## Итог

| Класс | Статей | Смысл |
|---|---|---|
| A | 34 | можно прогнать решателем |
| A? | 25 | вероятно можно прогнать |
| B | 97 | частичные/побочные данные |
| L | 42 | решёточные данные (отложено) |
| C | 1064 | не подходят |
| REF | 1 | опорная статья (Friesen et al., arXiv:2512.22198) |

По 59 статьям A/A?: 22 прогнаны (статус `done ...`), 37 прочитаны и записаны без прогона
(`recorded ... confirmed` — нужна фича, нет параметров или дубликат). Ошибок решателя не найдено;
найдено ~11 опечаток в статьях и одна проблема API (`summaries/SOLVER_FINDINGS.md`).

## Структура

| Путь | Содержимое |
|---|---|
| `MASTER.csv` | реестр всех 1263 статей: класс, модель, данные, `status`, `result` (вердикт или ссылка на отчёт) |
| `summaries/PHASE1_SUMMARY.md` | итоги классификации |
| `summaries/PHASE2_SUMMARY.md` | итоги прогонов |
| `summaries/SOLVER_FINDINGS.md` | `solve_mean_fields`: независимые Φ, Φ̄ → уход на границу 0.999 |
| `phase1/CLASSIFICATION.csv` | первичная ручная классификация (1188 статей без 75 пробных; актуальные классы — в `MASTER.csv`) |
| `papers/<arXiv>_<Автор><год>/` | отчёт по прогнанной статье: `result.md` + таблицы, сканы, параметры |
| `papers/_combined/LSM_vacuum_Metzger1993_Pirner1994/` | общий отчёт для hep-ph/9312252 и hep-ph/9410264 |
| `papers/_combined/QM_limit_SW/` | предел QM (Φ=Φ̄=1), используется в отчётах SW, Gupta, Tiwari |
| `full32/REPORT.md`, `full32/NOTES.md` | полный проход по 32 оставшимся статьям A: сводка и журнал по каждой |
| `full32_extra/` | прогоны этого прохода: CEP 0906.1324 и 0909.0289 (`cep/`), T_c Haas/Stiele 1303.3742 (`haas_stiele/`), уточнённый CEP Mintz (`mintz_refined.txt`), входные YAML и логи |

## Как читать `status` в `MASTER.csv`

- `done (phase2 | trial | sample10 | full32)` — прогнано решателем, отчёт в `papers/` или `full32_extra/`;
- `recorded (... confirmed)` — прочитано полностью, вердикт в столбце `result`;
- остальные классы (B, L, C) пока только классифицированы.

Скрипты прогонов (`tools/`, `runs/`), на которые ссылаются отчёты, сюда не перенесены
(лежат в старой папке `Desktop/Claude/work/paper_checks/`).
