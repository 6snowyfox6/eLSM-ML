# Фаза 1: классификация архива eLSM.zip (1263 статьи)

Дата: 2026-10-20. Решатель не изменялся. Полный реестр: `MASTER.csv` (по строке на статью),
детали классификации: `phase1/CLASSIFICATION.csv`, результаты пробных прогонов: `REGISTRY.csv`, `papers/`.

## Как делалось
1. Локально (32 ядра, ~35 с): извлечение текста всех PDF (`tools/extract_all.py`), метрики качества,
   поиск числовых параметров и подписей таблиц. Нечитаемых PDF нет; 11 «малотекстовых» проверены вручную — это не сканы.
2. Классификация: название + аннотация + найденные фрагменты (таблицы, числа) каждой статьи; для кандидатов —
   чтение нужных страниц. Отбор по ключевым словам использовался только для порядка, ничего не отбрасывалось автоматически.
3. Контроль качества: полнотекстовый поиск по всем статьям класса C на сочетание «SU(3) + напечатанные λ1, λ2, h_x, h_y».
   Найдено 8 статей, все обоснованно в C (PDG, NJL-обзор, двухцветная КХД, дубликаты фита PRD 87, SU(4)). Пропусков не выявлено.

## Кандидаты класса A по группам (одна группа ≈ одна модель/набор параметров)
Приоритет 1 — ключевые эталоны, 2 — независимые проверки, 3 — в основном дубликаты.

### SW-PQM: 2+1 quark-meson / Polyakov-quark-meson (Schaefer–Wagner и последователи) — 19 статей
- **p1 0808.1491 Schaefer & Wagner 2009 (PRD 79)** — ссылка [59] опорной статьи. Наборы параметров для m_σ=400–1200 (c≠0, c=0),
  вакуумные массы, **таблица вторых производных m_q² по мезонным полям** (нужна для открытой задачи №2).
- **p1 0910.5628 Schaefer, Wagner, Wambach 2010 (PRD 81)** — таблицы псевдокритических T_χ (лёгкий/странный конденсат, Φ)
  при разных T0 и m_σ: прямой эталон для сканов T_χ и для систематического сдвига 1–3 МэВ.
- **p1 0911.2464 Gupta & Tiwari 2010, 1301.3717 Tiwari 2013** — массы мезонов и углы смешивания от T в PQM (T0=270).
- **p1 0906.1324 Mao 2009** — независимая реализация 2+1 PLSM.
- p2: 1108.2941, 1212.1184, 1303.3742, 1308.3621, 2306.12382, 2007.13580.

### Tawfik-PLSM: группа Tawfik (та же, что у опорной статьи), m_σ=800, g=6.5 — 16 статей
- **p1 1509.07114** (параметры напечатаны: c=4807.84, λ1=13.48, m²=−(306.26)², h_l, h_s), **1412.2395, 1901.03293** (16 мезонов от T),
  **2502.01644** (сестринская статья опорной, формулы масс при T).
- p2: магнитное поле, изоспин, конечный объём — в пределе B=0, μ=0 сводятся к обычному PLSM.
- Многие статьи группы — фактически один и тот же расчёт; прогонять по одной-две на набор параметров.

### Kovacs-ePQM: eLSM + кварки + Поляков (Будапешт/Франкфурт) — 10 статей
- **p1 1601.05291 Kovács et al. 2016 (PRD 93)** — eLSM с векторными мезонами при конечной T/μ, **таблица производных
  m_q² по полям** (вторая независимая ссылка для задачи №2). p2: доклады 2014–2015, 2209.09568.

### LSM-vacuum / eLSM-vacuum и прочее — 9 статей
- Вакуумные наборы U(3)×U(3) LSM 1993–1999 (Metzger, Napsuciale, Törnqvist, Pirner) — быстрые проверки типа Lenaghan/Röder.
- 1909.12071 Zacchi 2019 — наборы параметров для разных m_σ (без/с вакуумным членом).
