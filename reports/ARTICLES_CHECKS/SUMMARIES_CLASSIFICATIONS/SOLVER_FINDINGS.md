# Находки по решателю (решатель не изменялся — только запись)

## 1. `solve_mean_fields`: минимизация по независимым вещественным Φ, Φ̄ некорректна (2026-10-20)

**Где:** `src/elsm/solver.py::solve_mean_fields` — минимизирует Ω по (σx, σy, Φ, Φ̄) с Φ, Φ̄ как независимыми
вещественными переменными в границах [0, 0.999].

**Проблема:** при вещественных независимых Φ, Φ̄ точка Φ = Φ̄ является седлом Ω по направлению Φ − Φ̄ (это направление —
мнимая часть петли Полякова), а не минимумом. Минимизатор уходит на границу Φ̄ = 0.999. Известно из литературы:
Mintz et al. 2013 (arXiv:1212.1184, разд. II E–F, сноска 4: «потенциал неограничен снизу» при вещественных Φ, Φ̄);
стандартные работы либо берут Φ = Φ̄ при μ = 0, либо ищут седловую точку (а не минимум) при μ > 0.

**Воспроизведение** (параметры опорной статьи, строка c≠0, μ = 0, стартовые точки по умолчанию):

| T, ГэВ | solve_mean_fields (σx, σy, Φ, Φ̄) | минимизация при Φ = Φ̄ (σx, σy, Φ) |
|---|---|---|
| 0.15 | 0.1087, 0.1035, 0.0247, 0.0247 | 0.1087, 0.1035, 0.0247 (совпадает) |
| 0.20 | 0.0512, 0.0896, 0.5128, **0.999** | 0.1007, 0.1008, 0.1816 |
| 0.23 | 0.0107, 0.0804, 0.588, **0.999** | 0.0411, 0.0877, 0.5067 |
| 0.26 | 0.0056, 0.0706, 0.6488, **0.999** | 0.0080, 0.0765, 0.6337 |

**Что затронуто:** `scripts/run_temperature_scan.py`, `scripts/audit_multiminima.py` (используют `solve_mean_fields`).
**Не затронуто:** `scripts/reproduce_paper_tables.py`, `verification/tscan.py` и все прогоны статей в `paper_checks/`
(везде Φ = Φ̄ при μ = 0) — поэтому совпадения T_χ с SWW 2010, Gupta, Tiwari, Rai, Mintz остаются в силе.

**Варианты исправления (для обсуждения, не реализовано):** при μ = 0 — накладывать Φ = Φ̄ (3 переменные);
при μ > 0 — либо Φ = Φ̄ = α (вещественная часть, метод Mintz 2013), либо поиск седловой точки (решение ∂Ω = 0 с выбором
экстремума, как в SWW/Tiwari/Tripathi), с явным выбором метода в API. Проверочные эталоны есть: Mintz 2013 табл. III
(оба метода, CEP), Tripathi 2025 табл. III.
