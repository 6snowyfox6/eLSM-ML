# Независимые проверки (verification)

Скрипты, которыми обоснованы исправления 2026-10-18 (см. `../docs/CHANGELOG.md`).
Пакету `elsm` они не нужны и не импортируют его — только numpy и scipy.

| Скрипт | Что проверяет | Запуск (из корня репозитория) |
|---|---|---|
| `derive.py` | Массы из лагранжиана (Eqs. 2, 5) против формул таблицы A1; находит опечатки η_NS и K0* (сравнение с напечатанными формулами) | `python verification/derive.py` |
| `reconstruct.py` | Восстанавливает вакуум авторов (σx = 2m_q/g = 0.109) и показывает, почему PCAC-вакуум (σx = 0.126) даёт m_π ≈ 436 МэВ; гипотезы по каону | `python verification/reconstruct.py` |

Скан T_χ по таблице III выполняет `scripts/reproduce_paper_tables.py`.
